# Abstract (arXiv, English)

We introduce the Algebra of Three (Tres): the set {-1,0,1} read as exclusion/potential/
actualization, with co-presence a+b=clamp(a+b) and interaction a*b=a*b. We prove that +
is commutative but non-associative (associator supported on exactly 4 ordered triples),
making history a state variable; the physical transformation monoid has 17 of 27 elements,
the complement being precisely the forbidden operations (measurement without contact,
erasure without interaction). We define RedTres, a neural node whose output co-presents
with an indelible memory register updated by algebraic rules, and demonstrate on a
smartphone: (i) native calibrated abstention emerges (separation 0.67); (ii) memory writes,
persists and heals exactly as predicted (-1+1=0), while double negation (-1*-1=+1) inverts
rather than heals; (iii) negative results delimit the theory: severe weight damage lies
outside the therapies' domain, and the +1 therapy is non-additive, interfering with
re-learning at high damage. We position Tres as an effective theory of memory and
hysteresis and a route to abstention-native language models. All experiments run on-device
(81 parameters, no GPU), with registered predictions and raw logs released.
